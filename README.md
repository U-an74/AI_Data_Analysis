# AI 데이터 분석: 데이터 기반 트렌드 분석


## 배운점 및 분석 포인트
1. **데이터 분석적 사고의 함양**
    - 데이터를 보고 “무엇을 알고 싶은지”를 3개 이상 정의할 수 있다.
        1) 전체 기간 동안 일별 처리 실적은 어떤 추세를 보이는가?
        2) 주간 단위로 묶으면 처리 실적의 추세에 변화가 있는가?
        3) 월별 처리 실적 규모는 어떻게 차이 나는가?

    - 결측치/이상치 개념의 이해 및 처리 기준 설정할 수 있다.  
        - 결측치: 수집 대상이었지만 값이 비어 있는 데이터
        - 이상치: 전체 흐름에서 유난히 크게 벗어나는 데이터
        - 처리 기준
            - 결측치/이상치 발생 시, 
                 - 먼저 원본 파일을 재확인한다.
                 - 실제 결측/이상이면 임의 보정 없이 제외 여부를 검토한다.
                 - 실제 오류가 아니라면 원인을 추적해 수정한다. 
                    - (예: 병합 키 형식 불일치 → 정규화 후 재병합)

    - 관찰과 가설을 구분할 수 있다.  
        - 관찰은 그래프에서 확인한 사실이고, 해석은 가설로 구분하여 다뤄야 한다.

2. **시계열 데이터 이해**
    - 트렌드: 시간에 따른 전체적인 증가·감소 흐름
    - 계절성: 일정 주기로 반복되는 패턴
    - 노이즈: 추세나 반복 패턴으로 설명되지 않는 불규칙한 변동
    - 본 프로젝트에 적용된 시계열 분석 기법 
        1) 이동평균 
        2) 구간별 통계
