# AI 데이터 분석: 데이터 기반 트렌드 분석


## 과제 목표
1. 데이터 분석적 사고
    - 데이터를 보고 “무엇을 알고 싶은지(질문)”를 3개 이상 정의할 수 있다.
        1) 처리 수량은 시간의 흐름에 따라 어떤 추세를 보이는가?
        2) 처리 수량은 품종별로 패턴이 있는가?
        3) 처리 대상 불량의 유형별 구성비는 시기별로 어떤 차이가 있는가?

    - 결측치/이상치 개념의 이해 및 처리 기준 설정 
    
    - 관찰vs가설의 구분
        - 관찰은 그래프에서 확인한 사실만을 말하며, 그를 기반으로 수행한 해석은 가설로써 구분되어야 한다. 

2. 시계열 데이터 이해
    - 트렌드:
    - 계절성:
    - 노이즈:
    - 적용된 시계열 분석 기법 
        1) 이동평균 
        2) 구간별 집계
        3) 구성비 
        4) 변화율

4. AI 활용 역량
    - 분석 목적에 맞는 질문을 AI에게 던지고, 생성된 코드/해석을 검증할 수 있다.
    - AI 도움을 받더라도 최종 판단(해석과 결론 도출)은 본인이 근거를 들어 설명할 수 있다.


## 최종 분석 결과물

1. 분석 리포트 (Markdown)
    - 입력/자료: 선택한 시계열 데이터(최소 100개 이상 데이터 포인트)
    - 출력/형식: REPORT.md에 분석 주제, 질문, 데이터 설명, 시각화, 인사이트, 결론/한계점 포함
      
2. 시각화 결과물 (REPORT.md 내 포함)
    - 총 4가지 시각화 분석 기법 사용, 5가지 메인 분석과 추가 및 보조 분석 각 1가지 수행
    - 출력/형식: 이미지 파일(png 등) 또는 노트북 출력 캡처를 리포트에 포함(링크 정상 동작)

3. Python 코드
    - 입력/자료: 원본 데이터 파일
    - 출력/형식: Jupyter Notebook(.ipynb)

4. GitHub 저장소
    - 포함: 코드, 리포트, (익명화 된)원본 데이터
